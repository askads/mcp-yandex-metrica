# Яндекс Метрика: Список целей счётчика — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Метрики:** Возвращает цели (конверсии), настроенные на счётчике Метрики (Management API).

Техническое имя: `list_goals`

## Какую задачу решает

> Я хочу посмотреть целей счётчика.

Возвращает цели (конверсии), настроенные на счётчике Метрики (Management API).

## Когда использовать

Используйте эту возможность, когда нужен результат «Список целей счётчика» без ручной работы в интерфейсе Яндекс Метрики. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `counterId` — **необязательно**. Идентификатор счётчика. По умолчанию YANDEX_METRIKA_COUNTER_ID.

## Что вернёт

Возвращает цели (конверсии), настроенные на счётчике Метрики (Management API).

## Что изменится в Яндекс Метрике

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть целей счётчика в Яндекс Метрике. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Идентификаторы целей нужны, чтобы запросить метрики конверсий (ym:s:goal<id>reaches / ym:s:goal<id>conversionRate) в get_statistics. Если counterId не передан, берётся YANDEX_METRIKA_COUNTER_ID.

Доступ также зависит от прав токена, квот и ограничений исходного API.
