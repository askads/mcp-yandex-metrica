# Яндекс Метрика: Начать подключение Метрики — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Метрики:** Первый шаг подключения Яндекс Метрики без правки конфигурации и без перезапуска клиента.

Техническое имя: `start_login`

## Какую задачу решает

> Я хочу начать подключение Метрики.

Первый шаг подключения Яндекс Метрики без правки конфигурации и без перезапуска клиента.

## Когда использовать

Используйте эту возможность, когда нужен результат «Начать подключение Метрики» без ручной работы в интерфейсе Яндекс Метрики. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Возвращает ссылку на страницу Яндекс OAuth.

## Что изменится в Яндекс Метрике

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Начать подключение Метрики в Яндекс Метрике. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Покажите ссылку пользователю целиком и попросите: открыть её в браузере под аккаунтом, у которого есть доступ к нужным счётчикам, подтвердить доступ и прислать показанный код подтверждения. Полученный код передайте в finish_login. Код действует 10 минут. Сам по себе код бесполезен для постороннего: обменять его может только этот сервер.

Доступ также зависит от прав токена, квот и ограничений исходного API.
