# Яндекс Метрика: Отключить Метрику — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Метрики:** Удаляет сохранённый токен Метрики с диска.

Техническое имя: `logout`

## Какую задачу решает

> Я хочу отключить Метрику.

Удаляет сохранённый токен Метрики с диска.

## Когда использовать

Используйте эту возможность, когда нужен результат «Отключить Метрику» без ручной работы в интерфейсе Яндекс Метрики. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Метрике

Инструмент удаляет локально сохранённый токен. Он не удаляет данные Яндекс Метрики и не отзывает доступ приложения на стороне Яндекса.

## Пример запроса

> Отключить Метрику в Яндекс Метрике. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Токен, заданный переменной окружения YANDEX_METRIKA_TOKEN, не трогает — его нужно убирать из конфигурации клиента вручную. Доступ, выданный приложению, остаётся активным на стороне Яндекса: отозвать его можно в Яндекс ID.

Доступ также зависит от прав токена, квот и ограничений исходного API.
