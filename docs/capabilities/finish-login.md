# Яндекс Метрика: Завершить подключение Метрики — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Метрики:** Второй шаг подключения: обменивает код подтверждения из start_login на токен доступа, сохраняет его в файл только для владельца (0600) и сразу проверяет живым запросом к Метрике.

Техническое имя: `finish_login`

## Какую задачу решает

> Я хочу завершить подключение Метрики.

Второй шаг подключения: обменивает код подтверждения из start_login на токен доступа, сохраняет его в файл только для владельца (0600) и сразу проверяет живым запросом к Метрике.

## Когда использовать

Используйте эту возможность, когда нужен результат «Завершить подключение Метрики» без ручной работы в интерфейсе Яндекс Метрики. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `code` — **обязательно**. Код подтверждения, который Яндекс показал пользователю после входа.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Метрике

Инструмент сохраняет токен в локальный файл с правами 0600 и проверяет подключение. Счётчики и отчёты Яндекс Метрики не изменяются.

## Пример запроса

> Завершить подключение Метрики в Яндекс Метрике. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

После успеха остальные инструменты работают немедленно — перезапускать клиент не нужно. Код одноразовый и живёт 10 минут: если он не принят, вызовите start_login заново и попросите свежий.

Доступ также зависит от прав токена, квот и ограничений исходного API.
