# Яндекс Метрика: Произвольный запрос к API Яндекс Метрики — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Метрики:** Универсальный запрос: обращается напрямую к любому пути API Яндекс Метрики — например "management/v1/counters", "management/v1/counter/{id}/goals", "stat/v1/data".

Техническое имя: `raw_request`

## Какую задачу решает

> Я хочу выполнить дополнительный запрос к API.

Универсальный запрос: обращается напрямую к любому пути API Яндекс Метрики — например "management/v1/counters", "management/v1/counter/{id}/goals", "stat/v1/data".

## Когда использовать

Используйте эту возможность, когда нужен результат «Произвольный запрос к API Яндекс Метрики» без ручной работы в интерфейсе Яндекс Метрики. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `path` — **обязательно**. Путь API, например "stat/v1/data" или "management/v1/counter/12345/goals".
- `method` — **необязательно**. HTTP-метод. По умолчанию GET.
- `query` — **необязательно**. Параметры строки запроса (ids, metrics, dimensions, date1, date2, ...).
- `body` — **необязательно**. Тело запроса в JSON для POST.
- `confirmWrite` — **необязательно**. Должен быть true для записи (POST или DELETE).

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Метрике

Исходный код помечает весь вызов «Произвольный запрос к API Яндекс Метрики» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить дополнительный запрос к API в Яндекс Метрике. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Нужен для эндпоинтов, у которых нет отдельного инструмента. `query` уходит в строку запроса, `body` отправляется как JSON для POST. GET выполняется свободно; POST и DELETE — это запись, им нужен confirmWrite=true.

Доступ также зависит от прав токена, квот и ограничений исходного API.

## Связанные MCP-инструменты

Связанных специализированных инструментов в этой группе нет.
