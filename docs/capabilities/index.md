# MCP-возможности Яндекс Метрики

Каталог содержит 8 публичных страниц — по одной для каждого зарегистрированного MCP-инструмента (tool) репозитория `mcp-yandex-metrica`. Страницы начинаются с задачи пользователя, объясняют результат и отдельно показывают, изменит ли вызов реальные данные.

Используйте этот каталог для выбора готовой возможности. Полные схемы параметров и ответы API остаются в [техническом справочнике](../TOOLS.md).

## Подключение

- [Статус подключения к Метрике](./auth-status.md) — Показывает, подключена ли Яндекс Метрика: есть ли токен, откуда он взят (переменная окружения YANDEX_METRIKA_TOKEN или сохранённый вход), когда истекает и где лежит файл с сохранёнными данными. **Воздействие:** только чтение.
- [Завершить подключение Метрики](./finish-login.md) — Второй шаг подключения: обменивает код подтверждения из start_login на токен доступа, сохраняет его в файл только для владельца (0600) и сразу проверяет живым запросом к Метрике. **Воздействие:** изменяет данные.
- [Отключить Метрику](./logout.md) — Удаляет сохранённый токен Метрики с диска. **Воздействие:** опасная операция.
- [Начать подключение Метрики](./start-login.md) — Первый шаг подключения Яндекс Метрики без правки конфигурации и без перезапуска клиента. **Воздействие:** только чтение.

## Статистика

- [Статистика](./get-statistics.md) — Запрашивает Reporting API Яндекс Метрики (stat/v1/data) по счётчику. **Воздействие:** только чтение.

## Счётчики и цели

- [Список счётчиков Метрики](./list-counters.md) — Возвращает счётчики Яндекс Метрики, доступные токену (Management API). **Воздействие:** только чтение.
- [Список целей счётчика](./list-goals.md) — Возвращает цели (конверсии), настроенные на счётчике Метрики (Management API). **Воздействие:** только чтение.

## Дополнительные методы API

- [Произвольный запрос к API Яндекс Метрики](./raw-request.md) — Универсальный запрос: обращается напрямую к любому пути API Яндекс Метрики — например "management/v1/counters", "management/v1/counter/{id}/goals", "stat/v1/data". **Воздействие:** опасная операция.
